# 神经本征对的后验证书：设计、数学与实验协议

> 状态：方法已实现（`src/nnschrodinger/solver/certify.py`，14 个单元测试通过）；
> 在真实 PINN 输出上的“包含率/紧度”实验待扫描结束后启动。
> 这份文档同时是论文 A 线的设计稿。

---

## 1. 问题：PINN 的“误差”目前不可信

现有 PINN 求解本征值问题的论文，几乎都只报告

```
|E_model − E_ref|,   overlap(ψ_model, ψ_ref),   ‖ψ_model − ψ_ref‖
```

这三个数都依赖**真解**。这带来两个方法论问题：

1. **能量准 ≠ 波形对**。与真解正交的污染分量对 Rayleigh 商是一阶不敏感的：
   若 ψ = √(1−ε²) φ₀ + ε φ₁，则
   `E[ψ] = E₀ + ε²(E₁−E₀) + O(ε³)`，能量误差是 ε²，而波函数误差是 ε。
   只报能量会系统性高估精度。
2. **“无监督”可能靠泄漏**。把真实 E 喂进残差项、用解析参考态做 deflation、
   用参考 overlap 做早停，都会让报告误差虚高。这些做法在代码里往往只差一行。

本项目的目标不是再刷一个能量误差，而是给神经本征对一个**不依赖真解、
可计算、可证伪**的双侧误差条。

## 2. 三个经典定理

设 H 是自伴算子，ψ 归一化，η = ⟨ψ, Hψ⟩，r = Hψ − ηψ。

### 2.1 Weinstein 界

谱中至少有一个本征值 λ 满足

```
|λ − η| ≤ ‖r‖。
```

它**不指定**是哪一个本征值，因此单独用很弱；但它是无条件的，且只需残差。

### 2.2 Temple 界（Kato–Temple）

若区间 [a, b] 内**恰有一个**本征值 λ，a < η < b，且

```
‖r‖² < (b − η)(η − a)，
```

则

```
η − ‖r‖² / (b − η)  ≤  λ  ≤  η + ‖r‖² / (η − a)。
```

**注意分母的配对方向**：下界除以**上**邻居的距离 `b−η`，上界除以**下**邻居
的距离 `η−a`。这与“直觉对称”的写法相反，但不是笔误：若 η > λ，正交污染
只能来自 λ 上方（否则 Rayleigh 商会低于 η）；若 η < λ，污染只能来自下方。
把两个分母写反会得到**高于真值**的下界。反例：H = diag(0, 10)、ψ 为两态
50/50 混合时 η = 5、‖r‖² = 25、a = −1、b = 10；正确下界是
`5 − 25/(10−5) = 0`（恰为真值），写反则是 `5 − 25/6 ≈ 0.833 > 0`，直接把
真值排除。测试 `test_temple_bounds_uses_correct_denominators` 锁住这一点。

这是双侧、二次收敛的界：残差减半，区间宽度约减为 1/4。
代价是必须知道一个“单态区间”，并且残差要足够小（上面的二次条件）——
残差相对谱隙太大时，本实现返回 `valid=False`，而不是给出无效区间。

### 2.3 Davis–Kahan 本征函数界

若 γ 是 η 到**除目标本征值外**其余谱的距离的下界，则本征函数夹角 θ 满足

```
sin θ ≤ ‖r‖ / γ。
```

它把能量证书升级为波函数证书。γ 不能随便取 `min(η−a, b−η)`：只有
[a, b] 被验证为单态区间时，这个值才是严格下界（见 §3）。

## 3. 关键工程点：用 Sturm 计数“验证”区间，而不是猜区间

Temple 界是条件性结论。常见错误做法是：用 Numerov/粗网格算一个近似谱，
取 `a = λ_{n−1} + margin`、`b = λ_{n+1} − margin`，然后把得到的数当作严格界。
`margin` 没有严格依据，证书就不是证书。

本实现改用 **Sturm 序列 / Sylvester 惯性定律**：

* 对离散 Hamiltonian `H_h − σI`（对称三对角）做 LDLᵀ 分解；
* 负主元个数 = H_h 小于 σ 的本征值个数；
* 计数是 O(N)，不需要参考谱，也不依赖任何近似本征值；
* 于是可以**验证**任意 [a, b] 是否恰含一个本征值；
* 也可以二分出相邻本征值的位置，自动构造单态区间。

复杂度：一次计数 O(N)，构造区间约 4 次二分 × 80 步 × O(N)，
N=2001 时仍是毫秒级。相对一次 PINN 训练（分钟到小时）可以忽略。

### 3.1 自动区间算法

```
k = count(η)                     # 小于 η 的本征值个数
在 η 左右分别二分出 λ_{k−1}, λ_k 的内外两侧
选离 η 更近的目标 λ_j
a = λ_{j−1} 的内侧（j=0 时取远低于 η 的点）
b = λ_{j+1} 的内侧（j=n−1 时取远高于 η 的点）
验证 count(b) − count(a) == 1
γ = min(η−a, b−η)
```

端点放在**邻居的内侧**而不是目标自己的两侧，否则 γ 会退化到目标与 η 的
距离（一个很小的数），夹角界会变成 π/2。这是实现里最容易写错的一处。

### 3.2 证书的自检

`certify_eigenpair` 的 `valid=True` 现在意味着：

1. η 严格在 (a, b) 内；
2. Sturm 计数确认 (a, b) 恰含一个 H_h 本征值；
3. γ > 0；
4. Temple 的二次条件 `‖r‖² < (b−η)(η−a)` 成立；
5. Temple 与夹角界都已算出。

第 4 条是这次修正后新增的：残差大但谱隙小的解（例如“能量/overlap 很好、
波形含高频噪声”的 PINN）不满足 Theorem 的前提，此时**不可认证**。
`valid=False` 的 reason 会明确区分“区间不是单态”“残差太大”“没有区间”等情况。

任何一条不满足都返回 `valid=False` 和具体原因，**不会**静默给出一个
“看起来很小”的区间。

### 3.3 浮点舍入裕度

Temple/Weinstein 的数学形式是精确的，但 η、r 和区间端点都是双精度数。
对“精确离散本征态”（例如无限深阱的 sin(nπx/L) 恰好是 H_h 的本征向量），
r 在 1e-11 量级，Temple 宽度 ~1e-22，小于 η 的 ulp——直接相减会得到
零宽度区间，甚至漏掉真值。因此证书在 Temple/Weinstein 端点上显式加
`1e-12 · max(1, |η|)` 的保守裕度，并从 γ 中扣除同样的裕度。对 PINN 的
r ~ 1e-2，这个裕度可以忽略；论文中应写成“证书在浮点舍入意义下成立”。

### 3.4 独立参考值

汇总脚本 `scripts/certify_saved.py` 用 `scipy.linalg.eigh_tridiagonal`
（LAPACK，独立于本项目的 Sturm 计数）计算同一 H_h 的参考本征值，并报告
`|λ_sturm − λ_LAPACK|`。如果两者不一致，说明 Sturm 计数或矩阵构造有 bug，
而不是“证书太宽”。这一步是防止用同一套代码自证。

## 4. 适用范围（必须写进论文）

证书对 **离散 Hamiltonian H_h** 严格，不是直接对连续算子严格：

```
H_h = −½ D₂ + diag(V),   D₂ 为二阶中心差分，Dirichlet 边界。
```

从 H_h 到连续 H 还有 O(h²) 的离散误差。严格扩展到连续算子需要额外的
截断误差界（例如用有限元/差分算子的谱逼近定理），这是后续工作。
当前论文里应明确写：

* 证书对象是 H_h；实验同时报告 h 和 H_h 的参考本征值，避免把离散误差
  误当成网络误差；
* 1D 束缚态在截断边界处 ψ≈0；对无限深阱，端点就是节点；对有限深阱，
  截断区间必须足够大，且报告边界处的 |ψ|；
* 单态证书只处理非简并、被谱隙隔离的本征值，区间含多个本征值时拒绝；
  简并/近简并由**簇证书**接管（`certify_subspace.py`，论文 §4）：重数由
  已验证的惯性计数测出，主子角由 ρ_F/δ 界定，认证对象是 m 维不变子空间；
* H 必须是自伴的；非自伴/复势不在范围内；
* **可认证性有阈值**：Temple 二次界要求 `‖r‖² < (b−η)(η−a)`。残差相对
  谱隙太大时（典型 PINN 的 H_h 残差 ~1），证书不是“很宽”，而是**不存在**。
  这不是实现保守，而是定理前提不成立。论文里应把 `certified` 作为
  与能量/overlap 并列的独立指标报告，并明确“不可认证”不等于“误差大”，
  它只说明残差信息不足以给出严格界。

## 5. 实验协议（A 线的生死实验）

### 5.1 问题与规模

| 维度 | 设置 |
|---|---|
| 势 | 谐振子 ½x²、无限深阱、有限深阱 |
| 态 | n = 0, 1, 2。n≥1 有两条路线：`certs5/*_1`（固定参考 E、无正交，**已声明的泄漏**，作为失败基线）与 `certs5_deflated` / `certs5_deflated2`（Rayleigh 商 + 用**学出来的**低能态做硬正交，链式投掉 ψ₀、ψ₁，无泄漏） |
| 种子 | 3 个（0/1/2） |
| 网络 | MLP（**width 64, depth 3**, Fourier 特征；`--seed-worker` 默认值，JSON 里逐 run 记录） |
| 训练 | `certs5` / `certs5_rayleigh` / `certs5_deflated` 组：exp5 同口径目标，10000 epoch（3000 时有限深阱停在非本征态）；`certs` 组：exp2 配置，5000 epoch；每个 run 保存 ψ |
| 证书网格 | N = 2001（h ≈ 0.006）；exp2 的正交化配置在 2500 点评估网格上保存 |

真正 leakage-free 的基态样本是 `certs5_rayleigh` 的 9 个 run（3 势 × 3
种子，Rayleigh 商残差）、`certs5` 的 9 个（可学习 E）与 `certs/learned0`
的 3 个；多态样本是 `certs5_deflated`（n=1）与 `certs5_deflated2`（n=2）
各 9 个（deflation 参考来自训练输出，不读解析解）。`certs5/*_1` 与 `certs/state1_deflated` 使用参考能量
或解析基，只用于 B 线的泄漏对照，不能算进 A 线的成功率。

**A 线主协议是 `certs5_rayleigh`**（§5.7.1）：E 在残差里取当前 ψ 的
Rayleigh 商，既无泄漏又与证书同口径。可学习 E 组保留作为对照——它暴露
了“训练目标没有被满足而证书仍然有效”这一类问题（工程记录 21）。

**分类必须看元数据里的 `residual_energy`，不能看组名**：第一版 `certs5`
（3000 epoch）的基态 run 也没有传 `--learned-energy`，残差里用的是参考
E，和 exp2 的 `residual_energy=reference` 一样是泄漏。那批结果已另存为
`runs/seeds/certs5_leaked_3k/`，只用于泄漏对照；A 线只统计
`residual_energy == "learned"` 且无 `orthogonalize` 的 run。详见工程记录 20。

### 5.2 指标

对每个 run 报告：

* `certified`: `valid` 是否为真；
* `containment`: 参考离散本征值 λ_ref 是否落在 `[temple_lower, temple_upper]`；
* `width`: Temple 区间宽度；
* `angle_bound`: 本征函数夹角上界；
* `residual_norm`；
* 滤波后的对应量（`cutoff`、`width_filt`、`angle_filt`、滤波造成的相对
  L2 改变 `rel_l2_change`），以及滤波前后 `state_index` 是否一致；
* 与 `|E_model − E_ref|` 的对比：证书宽度应覆盖真实误差（否则说明实现或
  假设有 bug），且通常比真实误差大 1–2 个数量级（这是后验证书的正常代价）。
  **比较对象必须是同一离散算子的 λ_ref**：H_h 与连续算子相差 O(h²)≈1e-6，
  滤波后的宽度（7.6e-8）会小于这个差，看起来像“界被违反”，其实只是
  认证对象不同。表里同时给 `E_disc_ref` 与连续 Rayleigh 商。

### 5.3 判定标准（go / no-go）

**Go**（继续做 A 线）：

* 包含率 ≥ 95%（在 12 个无泄漏 run 中：`certs5_rayleigh` 的 3 势 × 基态 ×
  3 种子，加上 `certs/learned0` 的 3 个；允许 1 个失败）；
* 成功认证的 run 中，中位宽度 < 10 × 真实能量误差；若原始宽度不达标，
  以**滤波后**宽度为准并同时报告原始值（滤波不读参考解）；
* 夹角界与真实 `arccos(overlap)` 同量级或更保守；
* 证书能在**不读取参考解**的情况下区分“好解”和“能量好但波形是杂波”的解。

**No-go**（转向 B/C 或改方法）：

* 大量 run 无法构造单态区间（说明 η 离任何本征值都远，训练本身失败）；
* 证书宽度比真实误差大 3 个数量级以上（后验证书失去实用价值）；
* 包含率低于 90%（说明离散/边界处理有系统性问题）。

### 5.4 对照：泄漏审计（B 线）

同一批 run 分三组：

1. `residual_energy = reference`：残差里直接用真实 E（旧配置，泄漏）；
2. `residual_energy = learned`：E 是可学习标量（真正无监督）；
3. `orthogonalize = True`：用解析参考态做 deflation（泄漏）。

对每组报告 `energy_abs_err`、`overlap`、`certified`、`width`。
预期：泄漏组能量误差更小，但证书宽度不一定更小；如果证书能识别出
“能量好但波形不对”，这就是 B 线最有力的结果。

### 5.5 早期观察（2026-10-27，含一次证书修正）

一个 64×3、2000 epoch 的 `rayleigh_learned` 小模型：

```
E_model = 0.50056,  overlap = 0.99999,  |E−E_ref| = 4.8e-4
H_h 残差 L2 = 1.12
```

在修正前的 Temple 公式下，这个 run 会给出“宽度 2.52”的区间；修正后发现
`‖r‖² = 1.26 > (b−η)(η−a) ≈ 1`，**Temple 二次界的前提根本不成立**，
该 run 应标为“不可认证”（`valid=False`，夹角界 π/2），而不是“宽度 2.52”。
这是 §2.2/工程记录 15 那次分母修正的直接后果——**大残差会让证书从
“很宽”变成“无效”**，两者在论文里必须区分。

原因不是证书 bug：网络在训练网格之间/边界附近有高频噪声，H_h 的二阶差分
把它们放大 1/h²，而 exp2 的训练残差是在随机点上用 autograd 评估的。

把训练目标换成证书同口径（实验五：固定 2001 点网格上的离散残差 + 边界 +
归一化，3000 epoch）后，同一个基态问题得到：

```
E_model = 0.500014,  overlap = 0.999998,  |E−E_ref| = 1.4e-5
H_h 残差 L2 = 0.361
证书能量 η = 0.5000197，同一离散算子的参考本征值 0.4999989
证书有效，Temple 宽度 = 0.260，夹角界 = 0.369 rad
```

宽度仍是 |η − λ_h|（2.1e-5）的约 1.3e4 倍——这是后验证书的固有保守性，
不是实现错误。延长训练（15000 epoch）把残差降到 0.0421、宽度降到
3.5e-3（见 §5.6），说明宽度确实随训练收敛；剩下的数量级差距要靠滤波
（§5.6）而不是更多 epoch。

> 2026-10-27 更新：这里的数字来自**修正能量项之后**的 3000-epoch 重训
> （工程记录 18）。修正前同一配置给出 E=0.500047、残差 0.328、宽度 0.216；
> 差别在能量项是否使用 Dirichlet 延拓，残差项定义未变。

结论：

* 证书能发现“能量/overlap 指标看不见”的问题；
* 训练目标与证书同口径可以把“不可认证”变成“可认证”，并把宽度降低一个量级；
* 但“可认证”不等于“紧”——宽度与真实误差之间仍差 3–4 个数量级，
  这是把 A 线定位为“评测协议 + 失败模式检测”而非“高精度认证”的主要依据。

后续实验应同时报告 `residual_rms`（autograd）与 `residual_norm`（H_h），
两者差距本身就是“离散残差是否被训练目标覆盖”的诊断量。

### 5.6 证书引导的谱滤波：把“不可认证”变成“紧界”

5.5 的瓶颈是高频分量：PINN 残差被波数 k 的分量主导，而 H_h 把它们放大
k²，能量却只受 O(k⁻²) 影响（Rayleigh 商是二阶变分）。既然这些分量对
**能量**几乎无贡献、对**证书**却是致命的，就可以在 Dirichlet 边界下把
ψ 投影到前 K 个正弦模式：

```
ψ_K(x_j) = Σ_{k=1}^{K} c_k sin(π k j/(M+1))，  c = DST-I(ψ_interior)
```

K 的选取完全后验：扫描一组 K，对每个滤波结果重新算证书，取**宽度最小**
且 `state_index` 与原始 ψ 一致的那个。不读取参考能量、不读取参考波函数。

已有结果（2001 点网格，实验五 3000-epoch 128×4）：

| 量 | 原始 ψ | 滤波后 (K=15) |
|---|---|---|
| H_h 残差 L2 | 0.361 | **0.00511** |
| Temple 宽度 | 0.260 | **5.22e-5** |
| 夹角界 (rad) | 0.369 | **0.00511** |
| 区间包含参考本征值 | ✓ | ✓ |
| ψ 的绝对 L2 改变 | — | 8.77e-5（相对改变 8.77e-5） |
| 真实 L2 误差（对解析基态） | 2.01e-3 | 2.01e-3 |

宽度随 K 先陡降后出现平台，再随 K 增大缓慢上升：K=8 → 0.306，
K=10 → 0.0282，K=12 → 1.46e-3，K=15 → 5.22e-5，K=18 → 5.22e-5，
K=20 → 5.24e-5，K=30 → 5.92e-5，K=60 → 6.54e-5，K=100 → 1.04e-4，
K=300 → 2.04e-4，K=600 → 0.137。**最小宽度点**正是“信号模式保留、噪声
模式截掉”的位置，而这个位置不需要任何真解就能找到；K 超过 ~10 之后，
再保留更多模式只会把噪声带回残差，宽度缓慢变大。

对 5.5 中不可认证的 exp2 小模型，滤波同样生效：残差 1.12 → 0.0107，
宽度有效（2.3e-4），区间包含独立参考本征值。

延长同口径训练到 15000 epoch 会进一步改善原始解（残差 0.0421、宽度
3.5e-3），滤波后为残差 1.9e-4、宽度 **7.6e-8**、夹角界 1.9e-4，区间仍
包含离散参考本征值。此时证书宽度已经**小于** H_h 与连续算子之间的
O(h²) 离散偏差（~1e-6）——引用时必须说明认证对象是 H_h。

> ⚠️ 这个 15000-epoch run 用的是**修正前**的能量项（工程记录 18）。
> 它保存的 ψ 及其证书仍然有效（证书只依赖 ψ 和 E，与训练方式无关），
> 但重新训练的数字可能不同；在修复损失后的重跑完成前，只把它当作
> “长训练能继续收紧宽度”的趋势证据，不要与 3000-epoch 结果直接对比。

“滤波是不是换了一个问题”可以直接量化：滤波前后 ψ 的相对 L2 改变在
修正后的 3000-epoch run 上是 8.8e-5（绝对 L2 改变 8.77e-5），15000-epoch
run 上是 1.4e-5。也就是说，被截掉的是万分之一的量级的高频成分，而它
贡献了残差的大部分——原始残差 0.361 与滤波后 0.00511 相差 70 倍。

必须诚实报告的三点：

1. 证书认证的是**滤波后**的 ψ_K，不是网络原始输出；论文表格必须两列并排，
   并给出滤波造成的 L2 改变。
2. 滤波只对 Dirichlet 边界成立（本项目全部势满足）；Neumann/周期需换基。
3. `state_index` 一致性约束不可省：去掉它时，激发态会被过度滤波成基态
   正弦波，得到一个更窄但“答非所问”的证书。

它的定位不是提升精度，而是**把不可验证的输出变成可验证的输出**，并给出
一个可复现的误差条。这比“再训练久一点”更接近“认证”的本意。

#### 5.6.1 把证书搬回网络原始输出（初等引理）

第 1 点质疑可以用一个三角不等式回答，不需要新定理。设 ψ 是网络输出、
ψ_K 是滤波结果、φ 是目标本征函数（‖φ‖=1），记 u=ψ/‖ψ‖、u_K=ψ_K/‖ψ_K‖。
则

```
sin∠(u, φ) = ‖u − (u·φ)φ‖
           ≤ ‖u − u_K‖ + ‖u_K − (u_K·φ)φ‖ + ‖(u_K·φ)φ − (u·φ)φ‖
           ≤ 2‖u − u_K‖ + sin∠(u_K, φ).
```

第一项直接由两个已保存的函数算出（不必用 δ 放大），第二项来自滤波后
证书的 Davis–Kahan 界 r_K/γ。因此**即使原始 ψ 自身不可认证，也能给出
它到真实本征函数的严格夹角上界**；滤波只损失 2‖u−u_K‖ 这一小段。

`filter_certificates.py` 每行都输出这一列（`angle_raw(搬回)`）以及用于
检验的列（`angle_raw(真实)`，对同一离散算子的本征向量直接计算）：

| 势 | 滤波后夹角界 | 搬回原始 ψ 的夹角界 | 真实夹角（离散本征向量） |
|---|---|---|---|
| 谐振子 | 3.9e-3 | 5.3e-3 | 8.7e-4 |
| 无限深阱 | 7.3e-10 | 5.9e-5 | 2.9e-5 |
| 有限深阱 | 0.560 | 0.560 | 1.0e-3 |

界都成立。谐振子/无限深阱上它把原始网络的夹角认证到 1e-5–1e-3 量级——
这是“证书约束网络输出本身”的直接证据，而不是“证书约束我构造的函数”。
有限深阱上滤波几乎不改变角度（0.560），界虽成立但没有信息量，原因见
§5.7（网络在势跳变处的短波误差无法与真实高波数分量区分）。

注意这是**初等引理**，不是新理论；它的价值在于把“认证对象是谁”这个
审稿人必问的问题变成一个可计算的量。

#### 5.7.1 Rayleigh 商残差取代可学习 E（2026-10-28）

§5.8 暴露的问题：`--learned-energy` 在有限深阱上 10000 epoch 只把 E 走到
−9.7（真值 −48.97），残差项 `H_hψ − Eψ` 实际没有被满足。修法是让残差里
的 E 取**当前 ψ 的离散 Rayleigh 商** η(ψ)=⟨ψ,H_hψ⟩/⟨ψ,ψ⟩：

* 它是 `‖H_hψ − Eψ‖` 对 E 的**最优**选择（对 E 求导为零）；
* 它与证书用的 η 完全同口径，训练目标与认证对象一致；
* 不需要给 E 单独调学习率，也不存在 E 不收敛的自由度。

`certs5_rayleigh`（3 势 × 3 seed，10000 epoch，`--rayleigh-energy`）的基态：

| 势 | 原始可认证 | 滤波 K | 滤波宽度 | \|E_filt−λ_h\| | 相对 L2 改变 |
|---|---|---|---|---|---|
| 谐振子 | 2/3 | 15 | 2.7e-5 – 9.3e-4 | 1.6e-6 – 7.4e-5 | 2.5e-4 – 1.6e-3 |
| 无限深阱 | 2/3 | 1 | 9.87e-12 | ~1e-13 | 4e-6 – 3e-5 |
| 有限深阱 | **3/3** | 400–600 | 0.37 – 0.73 | 1.3e-4 – 7.7e-4 | 6.5e-5 – 2.4e-4 |

与可学习 E 组相比，有限深阱的滤波宽度从 1.87–2.72 降到 **0.37–0.73**，
且 3/3 原始可认证（原为 1/3）；谐振子/无限深阱基本不变。这修掉了
“训练目标名不副实”的问题，也让 A 线的主协议从 learned-E 改成 Rayleigh。

#### 5.7.2 第一激发态：可学习 deflation（C 线，2026-10-28）

做法（`--deflate-from` + `--rayleigh-energy`，`scripts/exp5_certificate_training.py`）：

1. 先跑同 seed 的 Rayleigh 基态，保存 ψ₀；
2. 训练 n=1 时，每一步把网络输出投影到该 ψ₀ 的正交补
   `ψ ← ψ − ⟨φ,ψ⟩φ`（φ 归一化，内积用离散 L2）；
3. 保存的 ψ 是**投影后**的函数，证书认证的就是它。

关键是 φ 来自**训练输出**而不是解析解——因此这一步没有任何“把答案给
优化器”的泄漏；`deflate_overlap`（投影后再取一次内积）在全部 9 个 run
上都是 |·|≤1.1e-16，说明投影在浮点精度内精确正交。

结果（`runs/seeds/certs5_deflated`，3 势 × 3 seed，10000 epoch）：

| 谐振子 | 2/3 | 2/3 | 3.4e-5 – 3.6e-5 | 3.6e-6 – 3.7e-6 | 0.999997 – 0.999998 |

* **8/9 落到目标态且被证书确认**；比 §5.7 里谐振子/有限深阱上的 0/6 是
  质的变化。加上基态与下面的 n=2，27 个多态 run 中 **25 个**的滤波后区间

#### go/no-go 判定（`scripts/go_nogo.py`）

12 个无泄漏 run（9 个 `certs5_rayleigh` 基态 + 3 个 `certs/learned0`）：

* 包含率 **12/12 = 100%**（Go 门槛 ≥95%）；
* 中位滤波宽度 **5.0e-4**；中位宽度/误差 **38.0**（Go 要求 <10，
  No-go 是 >1e3）→ **紧度不达标**；最大比值 2.92e3 出现在有限深阱，
  那里的绝对宽度已从 learned-E 组的 1.87–2.72 降到 0.37–0.73；
* 夹角界覆盖离散本征向量的真实夹角 12/12，但有限深阱的界是 0.56–0.84 rad，
  没有信息量；
* 原始（未滤波）可认证 **7/12**（learned-E 组是 5/12）。

**统计功效**：12/12 的 Wilson 95% 置信区间是 [0.758, 1.0]，单靠 12 个
run 不能在 95% 置信度下断言“包含率 ≥95%”（零失败需要 n≈60）。论文里
应写“12/12 个 run 包含参考值”，而不是“包含率 ≥95%”。

**结论**：协议本身没有出现错误认证；但“紧”只在谐振子上成立，且高度
依赖后验滤波。按 §5.3 的自定标准，这是**窄义 Go、广义 No-go**。

### 5.9 经典基线与离散化 gap（审稿人必问）

**同一离散算子 H_h 的经典解**：用 LAPACK 三对角求解器取本征向量，再走
完全相同的证书流水线（`certify_eigenpair`，不滤波）：

| 势 | 证书宽度 | 夹角界 | 残差 |
|---|---|---|---|
| 谐振子 | 2.0e-12 | 6.1e-12 | 6.1e-12 |
| 无限深阱 | 9.9e-12 | 2.0e-9 | 2.0e-9 |
| 有限深阱 | 9.8e-11 | 3.6e-12 | 3.6e-12 |

也就是说证书机制本身能到 1e-12–1e-10；PINN 流水线（滤波后）在谐振子上
是 1.6e-5，相差 **7–10 个数量级**。论文必须正面回答“为什么不直接用
eigensolver”，答案只能是：这是**评测/诊断协议**，不是求解器。

**离散化 gap**：证书只对 H_h 严格。第一个本征值随 N 的收敛：

| 势 | N=501 | N=1001 | N=2001 | N=4001 | N=8001 | 阶 |
|---|---|---|---|---|---|---|
| 谐振子（λ_h−λ） | −1.80e-5 | −4.50e-6 | −1.13e-6 | −2.81e-7 | −7.03e-8 | O(h²) |
| 无限深阱 | −1.62e-5 | −4.06e-6 | −1.02e-6 | −2.53e-7 | −6.27e-8 | O(h²) |
| 有限深阱 | −1.89e-2 | −2.47e-3 | **+5.44e-3** | +1.83e-3 | −3.69e-6 | 非单调，界面/网格对齐 O(h) |

有限深阱在 N=2001 的离散误差（5.4e-3）比该 run 报告的连续能量误差
（5e-5 ~ 9e-4）大 6–100 倍：所谓“高精度”是离散网格和界面对齐的巧合。
论文不能把有限深阱的 `|E_model − E_cont|` 当作方法精度。

### 5.10 二维扩展：稀疏 LU 惯性计数（2026-10-28）

二维不是"把一维代码加一维"。一维用三对角 Sturm 计数验证"区间内恰有一个
本征值"，二维没有 Sturm 序列，但可以用 **Sylvester 惯性定律**：对
`A = A_h − σI` 做 LU 分解 `A = LU`，则 `U` 对角元的负号个数等于
`A_h` 小于 σ 的本征值个数。前提是**没有行列交换**——一旦主元交换，
`U` 的对角元就不再对应顺序主子式，计数无效。

实现（`certify2d.count_eigenvalues_below_2d`）对每一层保护都显式检查：

1. `splu(..., permc_spec="NATURAL", diag_pivot_thresh=0.0, options={"SymmetricMode": True})`；
2. 断言 `lu.perm_r`、`lu.perm_c` 都是恒等置换（否则直接报错，不静默降级）；
3. 断言 `min|U_ii| > 1e-13·scale`（主元退化时浮点符号不可信），失败则按
   `scale·1e-11·10^k` 扰动 shift 重试至多 6 次；
4. **分辨率下限**：`1e-9·scale`，`scale = max(1, ½(2/hx²+2/hy²) + max|V|)`。
   验证出的谱隙低于这个下限时，证书返回 `valid=False`，因为双精度下的
   惯性计数已经无法区分"单态"与"简并"。

第 4 条是二维新增的**安全阀**，也是开发中真实踩到的坑：一个简并态在
扰动重试后给出了 `valid=True`、宽度 9.5e-11 的假证书，而真实谱隙是
1.6e-14。一维后来也补了同样的下限（`certify._resolution_floor`）。

#### 二维离散化 gap：证书界定的是 H_h

| 势 | N=41 | N=61 | N=81 | N=101 | N=121 | 拟合 λ* | 纯离散阶 |
|---|---|---|---|---|---|---|---|
| harmonic2d \|λ_h−λ*\| | 1.39e-3 | 6.17e-4 | 3.47e-4 | 2.22e-4 | 1.55e-4 | 1.0007825701 | 2.00 |
| well2d \|λ_h−λ*\| | 5.07e-3 | 2.25e-3 | 1.27e-3 | 8.12e-4 | 5.64e-4 | 9.8696042046 | 2.00 |

λ* 是对 `λ(h)=λ*+c h²` 的最小二乘外推。方阱的 λ* 与 π²=9.8696044011
相差 **2.0e-7**，且误差单调、阶数恰为 2——这是整条流水线（惯性计数 +
二分 + 外推）的端到端校验。

谐振子要注意：无穷域解析值是 1.0，但盒 [-3,3]² 上的 Dirichlet 问题本身
的本征值是 λ*=1.0007826，比 1.0 高 7.8e-4——这是**区域截断**，不是离散误差。
所以谐振子的 `|E_model − 1.0|` 在 N≥81 后反而随 N 增大（1.65e-4 → 6.28e-4），
因为离散误差 (−c h²) 在减小、截断偏移是常数。论文里必须把它写成两列
（vs 解析 1.0、vs 盒内 λ*），否则"网格越细误差越大"会被审稿人当作 bug。

**因此二维报告的精度分两层**：网络对 H_h 的误差 1.7e-6 ~ 4.6e-5，
H_h 对盒内连续算子的误差 3.5e-4（N=81）。网络误差已经低于离散化误差
一个数量级以上——这是"证书有意义、但只能界定 H_h"的定量说明，也是
把二维扩展到三维/更多网格时的性能预算。

#### 二维搬运引理

二维的滤波截断在张量 DST 子空间 `span{sin(kxπx) sin(kyπy)}` 上，
`filtering2d.transported_angle_bound_2d` 用三角不等式
`sin∠(u,φ) ≤ 2‖u−u_K‖ + sin∠(u_K,φ)` 把滤波后的角度界搬回原始 ψ
（与一维同一引理；`‖·‖` 是 `L²_h` 离散范数，`u=ψ/‖ψ‖`）。
上表的"搬回界 ≥ 真实夹角"是逐 run 检查过的。

### 5.11 定向舍入计数（2026-10-28）

§3.3 的"浮点舍入裕度"一直是本协议最弱的一环：它靠经验扰动，不是证明。
`certified_count.py` 把它换成了区间算术——精度仍是 double，但每一步都强制
向外舍入（IEEE 754 正确舍入 ⇒ 单步误差 ≤ 半个 ulp，`nextafter` 外推一个 ulp）。

**一维**：用 LDL^T 的 pivot 比值递推，而不是行列式递推。
`d_k = (a_k−σ)d_{k−1} − b²d_{k−2}` 在区间里第 35–45 步就相对宽度 >1
（363 个 shift 上无一例外），因为它在谱的体量尺度上剧烈相消；
`q_k = (a_k−σ) − b²/q_{k−1}` 不会，因为 b²/q 只是对 a_k−σ 的小修正。
代价：每次计数 5 ms（浮点 0.4 ms），且 q 跨零时必须**拒绝**并报告主元下标。

- 结果：3 势 × 121 shift，361 认证、0 算错、2 拒绝；两次拒绝都在扫描最后一个
  shift 上，该 shift 与稠密谱的距离恰为 0（双精度里等于本征值）。
- 拒绝从不被四舍五入成整数——这是整个实现的意义。
- 计数二分可以给出**认证的本征值 bracket**；到达递推分辨率时返回最后一个
  已验证的区间，而不是失败。

**二维的本征值**：``certified_separable_brackets_2d`` 在二维计数上做二分，
不变式是 N(lo) <= k < N(hi)，所以 lo <= λ_k < hi。两个经验教训：初始区间必须以
hint 为中心**非对称**取中点（0.618 而不是 0.5），否则第一步就落在 hint 上，
而 hint 常常正是双精度里的本征值，计数必然拒绝；二分走到计数分辨率时应当
**收下最后的区间**而不是返回失败。

**二维**：可分势 V = Vx + Vy 时 H_h = Ax⊗I + I⊗Ay 精确成立，
`spec = {μ_i + ν_j}`，计数退化为两两求和比较。81×81 上 25 个 shift 全部认证、
零分歧、约 18 ms/次。不可分势**明确拒绝**（没有 Kronecker 结构就不猜）。
带状区间 LDL 的失败是量化的：361 未知量、10 个 shift 拒绝 6 个，
首次拒绝在第 174 步时相对枢轴宽度 0.93，且随 N 恶化——这是区间**放大**，
不是零主元，所以对称选主元救不了它。

驱动 `scripts/directed_count_report.py` → `runs/directed_count/stats.json`；
测试 `tests/test_certified_count.py`（11 项）。

### 5.12 连续算子的变分界（2026-10-28）

`continuous_bound.py`。要点有三条：

1. **上界免费**：λ1(H) = min R(u) <= R(u)，对任意 u ∈ H^1_0。P1/Q1 插值连续、
   边界为零，所以采样函数（含网络输出）插值后就是合法试探函数；没有插值常数，
   因为没有用到任何逆不等式。
2. **求积必须核对**：刚度项精确（一维分段常数；二维每变量次数 2，Gauss 精确）；
   势能项用 Gauss，只对低次多项式精确。代码同时用 3 点与 5 点规则，
   **两条区间不相交**才拒绝——用固定相对阈值会误判：二维项数 ~2.5e5，
   区间 padding 本身就接近 1e-11。
3. **下界不对称**：box 有 sinθ <= θ 的严格下界；有限深阱没有，而且它是反例。
4. **严格性只到“累加”这一层**（审稿式审计发现的）：三项积分的**求和**用区间
   算术外推，但单元积分本身（质量、刚度多项式、势能 Gauss 求和、V 在节点的
   取值）是双精度算的，舍入**没有被包围**。量级 ~1e-16 相对，比 bracket
   小十一个数量级，不改任何表格数字；但“上界严格”这句话只能说到“精确算术下
   严格、浮点求值差一个未包围的 ulp 级”。论文 §6.4 与模块 docstring 都按这个
   口径改写。要补上，必须让 V 以区间算术求值——这是下一步，不是已完成的。

驱动 `scripts/continuous_bound.py`（`--alignment` 单跑有限深阱的对齐研究），
测试 `tests/test_continuous_bound.py`（9 项）。

## 6. 可能被审稿人问的问题

**Q: 这不就是 Kato–Temple 界吗？**
A: 定理是经典的；贡献是**可计算性**与**验证协议**：
(a) 用 Sturm 计数把“单态区间”从假设变成可验证的计算；
(b) 把证书接到神经本征对上，作为训练/早停/模型选择的判据；
(c) 给出泄漏审计与包含率/紧度的系统实验。
我们不会声称发明了 Temple 界。

**Q: 为什么不用残差直接当误差？**
A: 残差是 ‖r‖，Temple 把 ‖r‖ 变成对 λ 的双侧界；两者量纲和含义不同。
Weinstein 界只需要 ‖r‖，但它不指定本征值，且通常比 Temple 宽得多。

**Q: 离散误差怎么办？**
A: 明确声明证书对象是 H_h；在实验里同时报告 h 和 H_h 的参考谱。
**2026-10-28 更新**：连续算子的一半已经被接上了——由极小极大原理，
P1/Q1 插值后的采样函数属于 H^1_0，其 Rayleigh 商是连续基态能量的严格上界，
不需要参考解也不需要插值常数（`continuous_bound.p1_rayleigh_bound`，
论文 §6.4）。**下界**仍是有条件的：box 用 sinθ <= θ 可以严格给出，
其余势没有；有限深阱更是一个反例，非变分相容的格式在跳点处离散值可以高于
连续值（论文 §6.5）。所以正确的说法不再是"open problem"，而是
"上界无条件、下界需要比较原理"。

**Q: 简并怎么办？**
A: 单态证书拒绝认证（区间含多个本征值），这是正确行为；**簇证书**接管：
`certify_subspace.py` 对一个 m 维试子空间做 Rayleigh–Ritz，用**已验证的
计数**测出 m，再以 `sinΘ ≤ ρ_F/δ` 给出主子角界（论文 §4、§5.7）。
实验九进一步把边界量化：用 λ(x²−y²) 做受控劈裂，单态证书在
**裂距 > floor 时才接受**——裂距/floor = 0.95 拒绝、1.01 接受，转折点
就在计数分辨率处（常规提议内缩 10%，谱隙 = 0.9×裂距；贴近 floor 时退回
二分兜底，谱隙 ≈ 裂距）。裂距 7.6e-6（ARPACK 轻易分辨）仍被拒绝——所以
“简并”不是正确的类别，可分辨性才是；
簇证书在整个扫描上 δ=7.397 不变。实验八：精确简并对验证重数 2、界 8.2e-13（真实 2.3e-16）；四个独立
网络 run 中三个塌到同一代表元、一个落到正交伙伴，簇证书**恰好**接受
含该伙伴的配对、拒绝塌缩配对（ρ_F=16.3 > δ=6.1），并给“噪声主导的
第二方向”一个宽两个量级但仍有效的界。多态仍用**逐个态 deflation**
（C 线，§5.7.2）：n=1 与 n=2 各 8/9 能落到目标态，链式版本一次投掉
ψ₀ 与 ψ₁。`harmonic_1/seed2` 跳过 ψ₁ 落到 ψ₂ 的失败仍由 state index
flag；第二方向可强制（deflate 已认证输出后重训），实验八已验证。

**Q: 把 ψ 滤到 15 个正弦模再认证，跟直接用 15-mode Galerkin 求解有什么
区别？后者不是更准吗？**
A: 是，而且这正是要说清楚的地方：滤波**不是求解器**，是诊断。区别有三：
(1) K 由运行时的证书宽度选出，不需要参考解，也不预设“15 就够”；
(2) 必须同时报告原始 ψ 的证书——原始宽度是网络自身的保证，滤波后的宽度
是“网络输出附近存在一个可认证函数”的证据；
(3) 报告滤波造成的相对 L2 改变（1e-3 / 1e-5），说明被移除的是噪声而不是
信号。若目标是解方程，当然应直接上谱方法；本协议的目标是在**没有真解**
时判断网络输出能否被信任、以及失败模式的指纹是什么。

**Q: 证书认证的是滤波后的 ψ_K，不是网络输出，那还叫“认证网络”吗？**
A: 可以把这个缺口量化，而且它很小。§5.6.1 的三角不等式给出
`sin∠(ψ,φ) ≤ 2‖u−u_K‖ + sin∠(ψ_K,φ)`：第一项是滤波位移（实测
4e-6–1.6e-3），第二项是滤波后证书。于是**原始 ψ 也有严格夹角上界**——
谐振子 5.3e-3、无限深阱 5.9e-5。这不是“换了一个问题”，而是把
“认证对象”从滤波函数搬回网络输出；代价是一个可计算的常数。

**Q: 用宽度选 K，会不会靠改变答案来降低误差条（循环论证）？**
A: 会，如果只最小化宽度。实现里加了 `state_index` 一致性约束：候选必须
认证到与原始 ψ 相同的本征态，且扫描报告完整保留（含被拒绝的候选）。
即便如此，滤波后的证书只能声明“存在一个附近的低模函数满足界”，不能
替代原始 ψ 的证书——所以两者必须并排报告。

## 7. 与文献的关系（写作时展开）

* Kato–Temple / Weinstein / Davis–Kahan：经典谱扰动理论，不是新结果；
* PINN 的 a posteriori 误差界：现有工作集中在**正问题**（forward PDE），
  例如用残差构造能量范数误差界；未找到针对**本征值问题**、且能验证
  单态区间的神经本征对证书；
* PINN 求解薛定谔方程：现有工作主要报告与参考解的误差，缺少不依赖
  真解的误差条；
* 谱方法/有限元的 a posteriori 本征值界：经典且成熟，但通常需要
  有限元空间与矩阵特征值求解；这里把它接到无网格神经表示上。

因此论文的定位应是：**把经典后验证书做成神经本征对的可计算协议，
并用它审计现有 PINN 评测**，而不是“提出新的谱界”。
